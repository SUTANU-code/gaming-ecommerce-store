# Gaming E-Commerce Store

A full-stack gaming e-commerce platform built using React, Spring Boot, MySQL, JWT Authentication, Docker, and Spring AI.

## Features

- User Registration & Login
- JWT-Based Authentication & Authorization
- Product Catalog Management
- Shopping Cart Functionality
- Order Management
- AI-Powered Product Assistance using Spring AI
- Responsive Modern UI
- RESTful APIs
- Docker Support

## Tech Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- Spring Boot
- Spring Security
- Spring AI
- JWT
- JPA/Hibernate

### Database
- MySQL
